# SWYNEX Task 3 — Interactive Power BI Dashboard

## Executive Summary

This project presents an **interactive executive dashboard** built in **Microsoft Power BI** as part of the **SWYNEX Data & AI Internship**. The objective was to transform a cleaned passenger dataset into a business intelligence solution that enables dynamic exploration through KPIs, visual analytics, and interactive filters.

## Business Objective

Develop a single-page dashboard that allows users to:

* Monitor key performance indicators in real time
* Analyze survival trends across demographic groups
* Compare passenger class performance
* Explore age, fare, and embarkation patterns using interactive filters

## Key Business Insights

### 1. Gender was the strongest survival factor

Female passengers achieved a **74.2% survival rate**, significantly higher than male passengers.

### 2. Passenger class influenced outcomes

First-class passengers recorded the highest survival probability, indicating the impact of socio-economic status.

### 3. Fare showed a positive relationship with survival

Higher ticket fares were generally associated with better survival outcomes.

### 4. Children demonstrated higher survival rates

Passengers in younger age groups experienced better survival compared to adults.

### 5. Interactive filtering enables deeper analysis

Users can instantly segment the dashboard by gender, class, embarkation location, and age to uncover more granular insights.
